We build plugins that put AI to work for your people. This is where we share them with you.

Each plugin lives in its own private repository, and you get access by invitation. Add a repository to Claude once. New versions then come to you through Claude, not through another download.

## Plugins

### [Personal Second Brain](https://github.com/augusto-plugins/personal-second-brain)

Build your own second brain and put it to work, with Claude. A morning brief, an evening wrap, inbox triage, your action list, a weekly review and meeting capture. Your brain is a folder of plain text notes on your own computer. Nothing leaves it unless you set up sharing yourself.

The repositories are private, so a link opens only after you accept your invitation.

## Get access

1. Use the Claude desktop app on a paid plan: Pro, Max, Team or Enterprise.
2. Make a free GitHub account if you don't have one, and email your username to [contact@augustodigital.com](mailto:contact@augustodigital.com).
3. Accept the invitation GitHub sends you.
4. Open the plugin's repository and follow the install steps in its README.

No GitHub account? You don't need one. Ask us for the download link and install the plugin from a zip file. With a zip, you install each new version yourself.
